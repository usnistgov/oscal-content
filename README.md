# OSCAL Examples

This directory contains numerous OSCAL examples in XML, JSON, and YAML formats based on [the latest OSCAL stable release](github.com/usnistgov/OSCAL/releases/latest).

These files are maintained by a Continuous Integration and Continuous Deployment (CI/CD) process that automatically converts source content into the alternate formats found in the many subdirectories of this repository. As a result, these example files should not be modified. Instead, the source of the file should be edited in the [src](src) subdirectories.

The structure and contents of the examples directory are as follows:

- [examples](examples): This directory contains sample OSCAL content organized by OSCAL model.
- [nist.gov/AI100-1/v1.0](nist.gov/AI100-1/v1.0): This directory contains OSCAL versions of the catalog defined by NIST Artificial Intelligence Risk Management Framework [AI RMF 1.0](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/AI_100_1_0_0/home), minor release 1.1.0.
- [nist.gov/CSF/v2.0](nist.gov/CSF/v2.0): This directory contains OSCAL versions of the catalog defined by NIST Cybersecurity Framework [CSF Version 2.0](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/CSF_2_0_0/home).
- [nist.gov/SP800-53/rev4](nist.gov/SP800-53/rev4): This directory contains OSCAL versions of the catalog, and low, moderate, and high baselines defined by NIST Special Publication (SP) [800-53 Revision 4](https://csrc.nist.gov/publications/detail/sp/800-53/rev-4/final). Since the SSP 800-53 rev4 is superseded by rev5, this directory is currently not updated and it is kept for historic reason only.
- [nist.gov/SP800-53/rev5](nist.gov/SP800-53/rev5): This directory contains OSCAL versions of the catalog, and low, moderate, and high baselines defined by NIST Special Publication (SP) [800-53 Revision 5](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_53_5_2_0/home), [SP 800-53B](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_53_B_5_2_0/home) and [800-53A](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_53_A_5_2_0/home) respectively. The SP 800-53 rev5 supersedes the SP 800-53 rev4. The latest version of this document is the [800-53 rev 5.2.0](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_53_5_2_0/home).
- [nist.gov/SP800-171/rev3](nist.gov/SP800-171/rev3): This directory contains OSCAL versions of the catalog defined by NIST Special Publication (SP) [800-171 Revision 3](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_171_3_0_0/home) and [800-171A Revision 3](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_171_A_3_0_0/home) respectively.
- [nist.gov/SP800-172/rev3](nist.gov/SP800-171/rev3): This directory contains OSCAL versions of the catalog defined by NIST Special Publication (SP) [800-172 Revision 3](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_172_3_0_0/home) and [800-172A Revision 3](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_172A_3_0_0/home) respectively.
- [nist.gov/SP800-172/rev3](nist.gov/SP800-171/rev3): This directory contains OSCAL versions of the catalog defined by NIST Special Publication (SP) [800-172 Revision 3](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_172_3_0_0/home) and [800-172A Revision 3](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_172A_3_0_0/home) respectively.
- [nist.gov/SP800-218/ver1](nist.gov/SP800-218/ver1): This directory contains OSCAL versions of the catalog defined by NIST Special Publication (SP) [800-218 Version 1.1.0](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_218_1_1_0/home).
- [src](src): This directory contains the source files for all the OSCAL examples located in this repository.
- [build](build): This directory includes [instructions](./build/README.md) and tools to build OSCAL dependencies, generate, convert, and check example content in this repository for release.
