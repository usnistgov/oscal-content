# The Artificial Intelligence Risk Management Framework (AI RMF 1.0) Digitalized in OSCAL Formats

This subdirectory contains the [Artificial Intelligence Risk Management Framework (AI RMF 1.0)](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf) digitalized in OSCAL formats.

Data source here is published into the appropriate target directory, meaning that /src/nist.gov/AI100-1/ver1/xml/ file is used to generate and publish information into the /nist.gov/AI100-1/ver1 directory, *in all supported formats* (XML, JSON, YAML).

OSCAL artifacts in the /nist.gov/AI100-1/ver1 directory are the preferred digital reference versions of the NIST AI RMF 1.0.
